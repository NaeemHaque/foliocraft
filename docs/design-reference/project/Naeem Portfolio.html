01 / About

Engineering for scale, contributing in the open.

I'm a software engineer and open-source contributor focused on building scalable products, developer tools, and web apps. At WPManageNinja, I work on WordPress product engineering, shipping software trusted by millions of users and businesses worldwide.

I contribute to the WordPress Open Source Project (Core, Plugins, Meta, Polyglots, Photos) and EmDash CMS. AI is now a core part of my workflow for research, planning, and debugging; the rest of my time goes to backend systems with a focus on architecture and clean code. I studied CSE at Sylhet International University, where programming contests shaped how I think and solve problems.
