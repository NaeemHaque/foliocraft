A fast, MVC-structured portfolio and blog theme with a Tailwind-built design, light/dark modes, and full Customizer control.

== Description ==

FolioCraft is a developer-focused portfolio and blog theme. It pairs a clean, type-driven design with a lightweight custom MVC structure and a Tailwind-built stylesheet, and exposes every piece of front-page copy through the Customizer — no code editing required.

Features:

* Light and dark color modes with a one-click toggle (respects the visitor's choice).
* One-page front layout: hero, about, skills, experience, selected work, open source, writing, and contact sections.
* Full Customizer control over identity, hero, about, skills, open source, social links, contact, accent color, and footer.
* Blog with single, archive, search, and 404 templates, threaded comments, and a web résumé page template.
* Custom menu support, custom logo, featured images, and translation-ready strings (text domain: foliocraft).
* Self-hosted fonts — no external requests, no user data sent to third parties.

Projects and Experience are managed by the free companion plugin, **FolioCraft Portfolio**, which registers those content types so your data stays put even if you switch themes.

== Installation ==

1. In your dashboard, go to Appearance > Themes > Add New > Upload Theme, choose the FolioCraft .zip, and click Install Now, then Activate.
2. Go to Appearance > Customize to set your name, bio, social links, accent color, and the rest.
3. (Recommended) Install the free **FolioCraft Portfolio** plugin to add and manage Projects and Experience entries.
4. Create a Page for your front page and a Page for your posts, then set them under Settings > Reading.

== Frequently Asked Questions ==

= How do I add projects and experience? =

Install and activate the free FolioCraft Portfolio companion plugin. It adds Projects and Experience post types under a single "Portfolio" admin menu. Keeping that content in a plugin means it survives a theme switch.

= How do I enable a contact form? =

By default the contact section shows a direct "Email me" button. To use a form instead, install any form plugin (for example, the free Fluent Forms) and paste its shortcode into Appearance > Customize > Contact > "Contact form shortcode" — e.g. [fluentform id="1"]. Contact Form 7, WPForms, and others work the same way.

= Does the theme load anything from external servers? =

No. Fonts are bundled with the theme and served from your own site. FolioCraft makes no third-party requests on the front end.

= How do I switch between light and dark mode? =

Use the sun/moon toggle in the header. The default mode is dark; the visitor's preference is remembered in their browser.
